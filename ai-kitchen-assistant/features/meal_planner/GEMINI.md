Day 2: Meal Planner & Grocery Assistant
Goal

Plan weekly meals based on ingredients, dietary goals, or budget.

Learning Focus

 * Working with lists, dictionaries
 * Weekly schedule representation
 * File storage (meal plans, pantry inventory)

Concepts

 * Meal Plan: List of meals for each day
 * Pantry: Inventory of ingredients user already has
 * Shopping List: Ingredients to buy

Features to Build

1. Plan Weekly Meals
Flow:

 * Ask for dietary goals and available ingredients

 * Generate 7-day meal plan using AI

 * Display in Rich table

2. Generate Shopping List

 * Compare meal plan to pantry
 * Output ingredients user needs to buy

3. Track Pantry Inventory

 * Add/remove items from pantry.json
 * Show current inventory

Success Criteria

✅ Can generate weekly meal plan
✅ Can create shopping list
✅ Can manage pantry inventory
