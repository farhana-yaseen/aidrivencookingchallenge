Day 3: Cooking Tutor

Goal
Provide step-by-step guidance while cooking.

Learning Focus
Sequencing instructions

Optional voice guidance
Time tracking for cooking steps

Concepts
Step: Individual instruction in a recipe
Timer: Countdown for cooking step
Tip: Optional cooking advice

Features to Build
Step-by-Step Guidance

Display instructions one by one

Wait for user confirmation to continue

Voice-Guided Instructions (Optional)

Use TTS library for reading steps aloud

Cooking Tips

Show tips for better taste/texture at each step

Success Criteria

✅ Can display recipe steps sequentially
✅ Can optionally read steps aloud
✅ Provides cooking tips
